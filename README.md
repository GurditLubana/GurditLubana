## Featured Project

### Azure Infrastructure Operations Lab

A practical Azure infrastructure project built with Bicep and PowerShell. The project includes modular infrastructure deployment, network segmentation, secure VM access, monitoring, alerting, and cloud operations automation.

**Main features:**

- Subscription-level Bicep deployment
- Separate resource groups for networking, compute, and operations
- Azure VNet, subnets, and Network Security Groups
- Linux virtual machine with SSH key authentication
- Azure Monitor, Log Analytics, CPU alerts, and NSG change alerts
- PowerShell scripts for VM lifecycle management and infrastructure health checks
- Cost-aware VM deallocation and resource management
